# Explore V2 — approved refinement, 6 November 2026

Preserve the existing realistic cabinet, copper lighting, atmospheric scene and
editorial typography. Repair the actual raster source, not overlapping plates.
Use the shared site grid/header geometry and a practical two-pane Archive Filter
Drawer with pending selections, group reset, chips, counts, apply/cancel.

The envelope contains a surprise from the entire current matching published set.
Selection commits results/URL and a collection overview; the individual remains
in an inert template until opening. Visit/Food/Place destinations stay distinct.
Another-memory keeps every search/filter, excludes the previous ID when there
are alternatives, and states the single-result limit honestly. Reset subtracts
only the explicit preset's values, preserving unrelated manual criteria.

Storyboard / ownership:

| State/action | Physical behavior | Content and cancellation |
| --- | --- | --- |
| Idle | Empty, complete recessed tray | Overview, ordinary reel available |
| Select | Slot lamp immediately on; package retracts locally if present | Fragment commits matching overview/results/URL |
| Prepare | Active indicator moves to dispense | Shared ExploreQuery selects published record, excluding previous ID |
| Dispense | Envelope moves from above the local aperture into the recess | 520ms first / 320ms repeat; tray clip and real foreground lip occlude |
| Ready | Envelope rests inside cavity; no floating below cabinet | Still overview; single-match draw control explained/disabled |
| Open | Flap hinges backwards; photo rises locally below upper rim | 260ms flap then 260ms insert; only then swap to individual |
| Revealed | Complete package stays in tray | One full-screen semantic link to correct detail |
| Another | Knob rotates 14deg at its actual center; retract then prepare | Same filter URL, a different ID when possible |
| Reset | Lower knob rotates -12deg; clears package | Removes preset contribution, retains unrelated criteria; overview |
| Mode | Shell, header and cabinet stay mounted, package clears | Async results, overview, controls and mode-specific drawer; no document navigation |
| Empty/error | No invented envelope | Explicit empty state or retry with committed data intact |

Scene owns request generation/AbortController; tray owns clipping and travel;
envelope owns flap/photo transforms. No shared transform owner or cross-screen
flight. New requests abort old stages. Results do not wait for opening. Reduced
motion skips physical travel but preserves the explicit open-to-reveal contract.
Status is a stable normal-flow row below the complete machine/tray bounds.
