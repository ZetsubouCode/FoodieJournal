## Execution environment and missing evidence

| Surface | Available observation | Unavailable / unverified |
| --- | --- | --- |
| Windows Chromium desktop | Playwright production build, actual loopback HTTP, browser keyboard, screenshots/pixel matching, normal-time video and CDP traces | Native page/text zoom blocked by returned-window ownership error; no native zoom input sent |
| Compact/tablet/landscape | Real Chromium layout at specified CSS viewports, emulated touch, doubled root text, reduced motion | Physical iOS/Safari/Android, mobile GPU, real touch calibration, OS magnification |
| Other engines | Actual launch probes recorded in `engines.json` | Firefox and WebKit executables absent; no browser installed for this task |
| Assistive input/output | DOM semantics, keyboard traversal and live-region changes | NVDA/JAWS/VoiceOver/TalkBack speech, switch/voice/Braille interaction |
| Maintenance/deployment | Real six-status browser responses; PHP exercises Laravel maintenance middleware against temporary isolated storage, JSON and Retry-After 120 | Owner/deployment maintenance not triggered; no reverse-proxy/deployed cache/device UAT |
| Performance | Three repeatable lab samples per cell, final build/fixture/network metadata, raw traces, synthetic 4× CPU diagnostics | Field LCP/INP/CLS, production load/media/cache/CDN, slower physical devices; synthetic CPU is not hardware |

The 44px internal goal is not a claim about every source-native hardware face. For example, the locked compact tube button measures 27×145px in the focus sample; its geometry is preserved, with existing keyboard/tap-target alternatives. Ordinary primary controls and card/filter/footer measurements are separate from that physical-art constraint.
