- **Code-inferred (C):** behavior inferred from a selector/function/branch; not reproduced in a browser in this audit.
- **Requested target (T):** approved direction, still requires implementation and acceptance.
- **Unknown (U):** insufficient evidence; never silently promote to implemented or passed.

## History and root cause findings

`4f6365b` is the older projector-era Explore commit, not a separately committed Memory Archive cabinet baseline. Both cabinet-on-Explore intermediate evidence and final Home migration are bundled in `801cc57`. The retained V1/V2 reports/captures are valid historical mood references; attributing all their geometry to 4f6365b would be false. No old code was restored.

The underline regression has direct evidence: `git diff 4f6365b b56db2c -- resources/css/home.css` deletes the left-origin pseudo-element transform; `git show 801cc57 -- resources/css/public-chrome.css` introduces the current static active-only rule. The older focused link had an outline adjustment; the new fully specified keyboard fill/re-entry contract is a requested improvement, not a falsely attributed historical behavior.

The environment still shares `.archive-page` warm surface overrides and `atmosphere.webp`. Differences arise from cascade, crop, fade and footer hierarchy, not unrelated page copies. The fixed 1280px cap creates 640px of unused total width at 1920px; whether a particular void is disproportionate is judged against the requested wide layout and content, not a universal rule against whitespace.
