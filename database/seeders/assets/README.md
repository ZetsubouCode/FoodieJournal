# Demo photographs

These bundled JPEGs are illustrative stock photographs from Unsplash. They are not photographs of the fictional places or evidence of actual visits. Each seeded visit identifies all content as demo data.

The exact source URLs are in [sources.json](sources.json). Photos use Unsplash's image endpoint with `auto=format&fit=crop&w=1600&q=80&fm=jpg`. See the [Unsplash license](https://unsplash.com/license). The photographs are included so subsequent demo seed runs require no network access.

The seeder copies these files into the private media disk and uses the application's normal media processor to generate the viewer, thumbnail, card, and hero variants. Nothing is linked into public storage.
